Bedside Clock – Verse Builder

Turns your reviewed verses.txt into the encrypted verses.json that the clocks download. Work down the steps in order. Nothing leaves this page: the text and key never get sent anywhere.

1Load your verses file

The plain-text master file. Each block: reference, verse, reflection, then a blank line. Lines starting with # are ignored.

Drop verses.txt here or click to choose it

2Check the report

Verses are measured with the same font and width as the clock's main screen. Click any row to preview it. Amber items are allowed but worth a look; red items should be fixed in the text file and reloaded.

3Encrypt and download

Paste the key from your Bitwarden note. The version number is read from the live file and bumped automatically.

4Publish

  1. On GitHub, open the WebTools repo and go to the folder holding the live verses.json.
  2. Choose Add file → Upload files, drop in the new verses.json (it replaces the old one), and commit.
  3. Wait a minute or two for GitHub Pages to update, then press Check live version above to confirm the new number is live.
  4. Clocks pick up the new verses on their next update check. Keep your edited verses.txt safe as the master copy.

    File format notes (for the firmware)
    
verses.json = {
  "format":  "bedside-verses",
  "version": <integer, plain text so the clock can compare before decrypting>,
  "built":   "<ISO date>",
  "alg":     "AES-256-GCM",
  "iv":      "<base64, 12 bytes>",
  "data":    "<base64, ciphertext followed by the 16-byte GCM tag>"
}
Additional authenticated data (AAD): UTF-8 bytes of "bedside-verses:v<version>"
  (so the plain version number can't be altered without decryption failing)
Decrypted plaintext (UTF-8 JSON):
  { "version": n, "built": "...", "verses": [ { "ref": "...", "text": "...", "reflection": "..." }, ... ] }
